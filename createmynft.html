CreateMyNFT

NFT-Ideen entwickeln, KI-Bilder erstellen und Metadaten über einen eigenen IPFS-Anbieter veröffentlichen. Wallet-Transaktionen erfolgen nur nach ausdrücklicher Freigabe.

Test & Direktkauf Hilfe & Kontakt Datenschutz Anbieter / Impressum Projekt auf GitHub

KI-gestützte Ideen

NFT-Konzepte, Beschreibungen und Bildentwürfe erstellen. Externe KI-Dienste sind vom Nutzer einzurichten.

IPFS-Metadaten

Bild und NFT-Metadaten über einen eigenen Pinata-Zugang hochladen und anschließend öffentlich überprüfen.

Externe Wallet

WalletConnect über Reown. Private Schlüssel und Seed-Phrasen werden nicht in CreateMyNFT eingegeben.

Blockchain-Testnetz

Base Sepolia wurde mit MetaMask auf einem Android-Gerät erfolgreich getestet: eigener ERC-721-Contract und zwei gemintete NFTs. Echte Verkäufe auf Base Mainnet sind noch nicht freigegeben.

So erkennst du CreateMyNFT

Offizieller Projektname: CreateMyNFT. Herausgeber: MEMVEXA-by-MW. Offizielle Website: memvexa-by-mw.github.io/memvexa-website/createmynft.html.

Die angezeigte Website allein beweist noch keine Verifizierung durch Trust Wallet oder WalletConnect. Solange eine Wallet „nicht verifiziert“ anzeigt, prüfe die Quelle besonders genau und bestätige keine unbekannten Transaktionen.

Sicherheit: Für Tests ausschließlich Base Sepolia (Chain-ID 84532) verwenden. Eine Transaktionsanfrage auf Ethereum Mainnet (Chain-ID 1) abbrechen. Keine Seed-Phrase eingeben. Netzwerk und Gebühr immer direkt in der Wallet kontrollieren.

Erfolgreicher Testnetz-Nachweis

Am 13. Oktober 2026 wurden zwei NFTs mit CreateMyNFT auf Base Sepolia gemintet (Token-IDs 0 und 1). Bild, IPFS-Metadaten und Besitzerzuordnung wurden unabhängig geprüft.

NFT #0 auf Blockscout · NFT #1 auf Blockscout

Das Testnetz bestätigt die Technik, nicht einen realen Marktwert oder funktionsfähige Mainnet-Verkäufe.

Status: CreateMyNFT befindet sich in der Erprobung. Weder profitable Verkäufe noch vollständige Marktplatz-Unterstützung oder eine Zertifizierung durch Trust Wallet werden zugesichert.
